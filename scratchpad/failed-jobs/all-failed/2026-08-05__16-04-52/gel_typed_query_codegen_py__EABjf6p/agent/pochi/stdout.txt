## EdgeQL Query Files (4 files)

1. **`app/queries/list_region_growers.edgeql`** — Parameters: `<str>$region_code`, `<optional float64>$min_kilograms`, `<array<str>>$certifications`. Returns every Grower in the region with matching Batch objects, filtered by optional kg threshold and certification list. Uses `array_unpack` + `intersect` for certification matching and `exists` + `if/else` for optional min_kilograms.

2. **`app/queries/get_batch_detail.edgeql`** — Parameter: `<str>$code`. Returns at most one Batch with nested grower/region data and `inspection_count` computed via `count(.<batch[is Inspection])`.

3. **`app/queries/record_inspection.edgeql`** — Parameters: `<str>$batch_code`, `<str>$inspector`, `<bool>$passed`, `<array<str>>$defect_codes`, `<int64>$severity`. Single query that inserts an Inspection and creates Defect objects per defect code, returning the inspection's id, inspector, passed, defect_count, and batch_code.

4. **`app/queries/region_totals.edgeql`** — Parameter: `<array<str>>$region_codes`. Returns per-region aggregates (grower_count, batch_count, total_kilograms) computed entirely in EdgeQL.
