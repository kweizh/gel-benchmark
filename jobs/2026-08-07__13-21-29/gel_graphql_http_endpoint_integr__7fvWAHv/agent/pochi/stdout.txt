- `retire_service(name)` / `delete_service(name)` — raises `ServiceNotFound` when service doesn't exist
- `verify_parity()` — cross-checks HTTP GraphQL vs binary protocol results
- `build_report()` — returns full report with endpoint, teams, pages, and parity

**Report command (`report.py`)**: Running `python3 report.py` from the project root creates `out/report.json` with the `build_report()` output and exits with status 0.
