### Schema Structure & File Layout

Three modules have been declared in their respective files under `dbschema/`:

1. **`dbschema/util.gel` (Module `util`)**
   - **`util::money_round(amount: decimal) -> decimal`**: Rounds amount to 2 decimal places using standard Gel `round` semantics (ties away from zero).
   - **`util::money_round(amount: decimal, places: int64) -> decimal`**: Overloaded function to support rounding to custom places (including zero or negative).
   - **`util::total_of(variadic amounts: decimal) -> decimal`**: Sums all variadic amounts, returning `0.0` when no arguments are provided.
   - **`util::apply_discount(amount: decimal, pct: decimal, floor_amount: optional decimal) -> decimal`**: Reduces amount by `pct` percent, rounds to 2 decimal places, and enforces a `floor_amount` if provided.
   - **`util::gross_with_tax(net: decimal, named only tax_pct: decimal = 0) -> decimal`**: Computes net increased by `tax_pct` percent (passable *only* by name).
   - **`util::installments(total: decimal, count: int64) -> set of decimal`**: Divides total into `count` installments, returning a set of decimals whose sum is exactly equal to `total`.

2. **`dbschema/billing.gel` (Module `billing`)**
   - **`billing::Customer`**: Holds required `name` (unique) and `discount_pct` (defaulting to `0`).
   - **`billing::Invoice`**: Holds required `code` (unique), required `customer`, required `paid` (defaulting to `false`), optional `minimum_charge`, required `installment_count` (defaulting to `1`), plus computed backlinks/properties:

3. **`dbschema/reports.gel` (Module `reports`)**
